### 🎮 Game Development dari Scratch
Membangun game engine dengan `HTML5 Canvas 2D` tanpa library seperti Phaser.js mengajarkan cara kerja **game loop** (`requestAnimationFrame`), collision detection, entity management, dan frame-budget optimization. Hasilnya: game yang jalan stabil di 60 FPS.

### 🔊 Web Audio API & Procedural Sound
Belajar menciptakan sound effects secara programatik menggunakan **OscillatorNode**, **GainNode**, dan **BiquadFilterNode** — tanpa file audio sama sekali. Suara tembakan, explosion, dan background hum semuanya disintesis real-time.

### 🎨 Design System Architecture
Membangun **custom Tailwind config** dengan design tokens yang konsisten (warna, spacing, tipografi) mengajarkan pentingnya sistem desain sebelum coding. Semua komponen saling kohesif karena pakai variabel yang sama.

### 🚦 SPA tanpa Framework
Mengimplementasikan **client-side routing** dan **section switching** dengan vanilla JavaScript — memahami bagaimana framework seperti React/Vue bekerja di balik layar.

### 📐 CSS Advanced Techniques
- **Glassmorphism**: kombinasi `backdrop-blur`, `opacity`, `background-color` semi-transparent
- **Neon Glow**: custom `box-shadow` multi-layer dengan blur radius
- **Ambient Lighting**: `blur-[120px]` gradient divs sebagai atmospheric background
- **Micro-animations**: `transition`, `hover:scale`, `animate-pulse`, `animate-ping`

### 🤝 Collaborative Git Workflow
Belajar bekerja dalam tim dengan **GitHub** — branching strategy, pull requests, resolving merge conflicts, dan menjaga history commit yang rapi dan bermakna.
